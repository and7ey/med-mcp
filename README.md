# med-mcp

Два MCP-сервера для личных медицинских кабинетов:

* **ЕМИАС** — медкарта и запись к врачу в Москве (`lk.emias.mos.ru`);
* **SmartMed** — медкарта и запись в клиники Медси (`smartmed.pro`).

Серверы работают с вашим аккаунтом: показывают данные медкарты и помогают
записаться к врачу. Вход выполняется на официальном сайте, пароль и код из SMS
не проходят через чат.

> Проект не связан с ДЗМ, ЕМИАС, Медси и SmartMed. API неофициальные и могут
> меняться.

## Установка

Нужен **Google Chrome** — вход открывается в нём.

### Claude Desktop

1. Скачайте в [Releases](../../releases) файл `.mcpb`:
   * `emias-medcard-mcp-*.mcpb`
   * `smartmed-mcp-*.mcpb`
2. Откройте файл — Claude Desktop предложит установить расширение.
3. Если при установке попросит установить `uv`, согласитесь: он нужен для
   запуска расширения.
4. При первом запуске выберите локальную папку для состояния (не облачную).

### OpenCode

1. Скачайте в [Releases](../../releases) бинарник для своей системы:
   * macOS Apple Silicon — `*-darwin-arm64`
   * macOS Intel — `*-darwin-x86_64`
   * Windows — `*-windows-x86_64.exe`
2. Положите файл в удобную папку.
3. Добавьте сервер в глобальный конфиг OpenCode (`~/.config/opencode/opencode.jsonc`):

```jsonc
{
  "mcp": {
    "servers": {
      "emias": {
        "type": "local",
        "command": ["/полный/путь/emias-medcard-mcp-...-darwin-arm64"],
        "timeout": { "startup": 120000, "catalog": 60000, "execution": 120000 }
      },
      "smartmed": {
        "type": "local",
        "command": ["/полный/путь/smartmed-mcp-...-darwin-arm64"],
        "timeout": { "startup": 120000, "catalog": 60000, "execution": 120000 }
      }
    }
  }
}
```

На Windows путь заканчивается на `.exe`. Если macOS блокирует запуск,
разрешите программу в «Системных настройках → Конфиденциальность и
безопасность».

### Из исходников

```bash
git clone https://github.com/and7ey/med-mcp.git
cd med-mcp/emias-mcp      # или smartmed-mcp
python3 -m venv .venv
.venv/bin/pip install -r requirements-mcp.txt
.venv/bin/python run_server.py
```

## Первый вход

1. Вызовите `session_status` — сервер скажет, нужен ли вход.
2. Вызовите `open_bootstrap` — откроется Chrome на официальной странице.
3. Войдите там: телефон, пароль (если нужен) и код из SMS.
4. Вызовите `bootstrap_status`, затем `quick_login`.

Пароль и код из SMS вводятся только на сайте сервиса. В чат их присылать
не нужно, и сервер их не запрашивает.

## Приватность

* Токены доступа не попадают в чат и в файлы проекта. На macOS они хранятся в
  Keychain; на Windows и Linux — в локальном файле с ограниченными правами.
* Журналы содержат только технические события: этап, код ошибки, HTTP-статус.
* Скачанные документы сохраняются только на ваш компьютер.
* Сервер никуда не отправляет ваши данные, кроме запросов к официальному API
  сервиса.
* Никакой телеметрии и аналитики нет.

## Ограничения

* API неофициальные: сервис может изменить формат, и сервер потребует
  обновления.
* Запись к врачу — реальное действие. Сервер сначала показывает детали и
  создаёт запись только после отдельного подтверждения. Отмена — так же.
* Сборки для Windows и Linux собираются автоматически, но проверены вручную
  только на macOS.
* Вход работает через Google Chrome; другие браузеры не поддерживаются.
