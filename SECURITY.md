# Безопасность

## Секреты

Проект не содержит токенов, паролей, кодов из SMS, cookies и персональных
данных. Не присылайте их в issues, pull request или обсуждения.

Токены, полученные при входе, хранятся:

* macOS — в системном Keychain;
* Windows и Linux — в локальном файле с ограниченными правами.

Файлы состояния и журналы не попадают в репозиторий: они лежат в домашнем
каталоге пользователя и исключены через `.gitignore`.

## Сообщения об уязвимостях

Не создавайте публичный issue. Напишите владельцу репозитория приватно и
опишите проблему без токенов и персональных данных.
